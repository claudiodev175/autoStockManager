> ⚠️ **Projeto em fase inicial de desenvolvimento**

Sistema web para gerenciamento de estoque de autopeças, desenvolvido com **Angular 19** no frontend e **Spring Boot 3** no backend.

---

## 🎯 **Sobre o Projeto**

Este projeto está sendo desenvolvido para aprendizado e prática das tecnologias:
- **Backend:** Java com Spring Boot 3 (Spring Security, JPA, JWT)
- **Frontend:** Angular 19 (TypeScript, RxJS, Angular Material)
- **Banco de Dados:** MySQL Workbench 8.0
- **Testes de API:** Postman

O objetivo é criar um sistema funcional de estoque com cadastro de produtos, fornecedores e controle de movimentações.
